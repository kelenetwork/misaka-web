# misaka-web

Next.js 15 backend/API scaffold for misaka.io VPS inventory monitoring and automated order tasks.

## Commands

- `npm install`
- `npx drizzle-kit generate`
- `npm run build`
- `npx vitest run`
- `docker build -t misaka-web:test .`

## Notes

- Frontend files are placeholders for 修一.
- misaka.io login/order details intentionally contain TODO placeholders until real browser captures are available.
- Copy `.env.example` to `.env` locally and never commit secrets.
